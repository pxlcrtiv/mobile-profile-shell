# Mobile Profile Shell

A stunning mobile-first interactive portfolio website that showcases professional profile, projects, and skills in an immersive app-like interface.

## ✨ Highlights

- 📱 **Mobile-First** — Immersive phone interface with smooth animations
- 🎨 **Modern Design** — Beautiful gradients, shadows, and micro-interactions
- 🌙 **Dark Mode** — Auto-detect or manual toggle
- ⚡ **Fast** — Optimized with code splitting and lazy loading
- ♿ **Accessible** — Keyboard navigable, screen reader friendly

## 🛠️ Stack

React 18 · TypeScript · Vite · Tailwind CSS · shadcn/ui · React Router · Lucide Icons

## 🚀 Quick Start

```bash
git clone https://github.com/pxlcrtiv/mobile-profile-shell.git
cd mobile-profile-shell
npm install
npm run dev
```

## 📦 Build & Deploy

```bash
npm run build
```

Deploy the `dist/` output to any static host (GitHub Pages, Cloudflare, S3, or any VPS).
